一、给 AI 的使用说明

请把本文件作为当前任务的参考资料。按以下原则分析家装问题：
1. 将风格、颜色、图案、触感、基材、饰面、加工方式和安装方式分别判断。
2. 对图片分别输出“可直接观察”“合理推测”“需要资料确认”。图片未显示的内部构造、品牌、厚度、性能和价格，不编造。
3. 可以描述“呈现洞石纹”，不能直接确定“天然洞石”；可以描述“皮纹表面”，不能直接确定“真皮”。
4. 风格允许多标签。不要仅凭米白色就断言奶油风，仅凭粗糙墙面就断言侘寂。
5. 施工尺寸、材料厚度、胶粘剂、固定间距、开槽深度和承载能力未提供时，标为待核验。示意图不是施工图。
6. 如果有联网能力，优先打开文末官方来源；没有联网能力时说明只依据本文件。文件里的链接不等于已经读取链接中的全部图片和正文。
7. 趋势回答注明年份、地区与证据类型。品牌预测、用户搜索热度、实际装修调查和设计建议分别表述。
8. 澳大利亚实际施工应核对当地现行要求和具体产品系统，不把中国节点或美式教程直接称为澳洲合规做法。
9. 推荐材料时同时说明外观、触感、用途、维护和加工限制。不得从营销名推导防水、防火、耐磨或耐污性能。
10. 图片分析支持审美建议与初步识别。需要采购或施工时，请求产品型号、样板或节点图等必要依据。

二、风格知识：常见标签及识别线索

以下是知识库的起始分类，不是全部风格都在2026年同样流行的排名。英文名是检索辅助，部分中文营销名称没有严格对应英文定义。

STYLE-01 暖极简 / Warm minimalism
识别：轮廓简洁、视觉杂物少、柔和暖色、天然或仿天然纹理，细节克制。
常见色调：暖白、米色、灰褐、沙色。
常见材料：浅木饰面、哑光石纹、亚麻、肌理涂料。
关联节点：齐平收口、阴影缝、隐蔽把手、薄边框。
误判：简洁不等于低施工成本；隐藏收口通常更依赖基层精度。

STYLE-02 自然现代 / Organic modern
识别：现代布局与自然纹理结合，常有圆润家具和有机轮廓。
色调：奶白、棕、陶土、低饱和绿。
材料：木、石、编织物、棉麻、陶器。
节点：圆弧转角、木石交接、层次照明。

STYLE-03 Japandi / 日式与北欧融合
识别：安静、重功能、留白、低矮家具，常以深浅木色形成对比。
色调：米白、浅灰褐、自然木色，少量深棕或黑。
材料：木皮、纸感表面、棉麻、陶器。
误判：不是日式家具与北欧家具随意混搭，也不等同于侘寂。

STYLE-04 侘寂取向 / Wabi-sabi inspired
识别：对自然变化、朴素质感和不完全对称的欣赏，通常有低对比与手工感。
材料：木、石、陶、灰泥或类似视觉效果的涂层。
误判：开裂、漏水、脱层和劣质施工不是侘寂的验收标准；真实瑕疵不能以风格掩盖。

STYLE-05 奶油风 / 中文市场风格标签
识别：低对比暖浅色、软性轮廓、柔软织物，常配圆弧家具。
材料：浅木、米白石纹、布艺、哑光涂层。
误判：缺乏标准英文一一对应；不要自动译成一种国际统一风格。

STYLE-06 现代海岸 / Contemporary coastal
识别：明亮、轻盈、通透，与海岸环境有关，通常不需要大量航海装饰。
色调：沙白、浅木、淡蓝绿。
材料：木、亚麻、藤编、自然石纹。
区域说明：室内审美与沿海环境的材料耐候要求是不同判断。

STYLE-07 北欧 / Scandinavian
识别：功能性、清晰线条、浅色背景、自然木材、舒适纺织品。
色调：白、浅木、灰，允许局部彩色。
误判：不局限于纯白房间。

STYLE-08 中世纪现代 / Mid-century modern
识别：较清晰的几何家具、细腿、木色、复古轮廓。
色调：胡桃木、橄榄绿、焦糖、芥末黄等组合。
材料：木、皮革、织物、金属、玻璃。
英文说明：这里的 mid-century 指20世纪中期设计语境，不是欧洲中世纪建筑。

STYLE-09 现代轻奢 / Contemporary luxe（近似检索词）
识别：石纹、金属、精细比例与软装层次，视觉更强调精致。
色调：米灰、深棕、香槟色或少量黑金。
材料：石材或石纹板、木皮、皮革、金属。
误判：金色越多不代表质量越高，镜面越多不代表更高级。

STYLE-10 法式现代 / Contemporary French-inspired
识别：线脚或古典比例与现代家具结合，可能有弧形门洞、木地板和石材。
误判：装饰线条不是结构构件；线脚节点与尺寸需要单独设计。

STYLE-11 新中式 / Contemporary Chinese-inspired
识别：传统比例、屏风或格栅、木色与当代功能结合。
色调：浅中性色、深木、墨色，局部传统色。
误判：格栅可以出现在多种风格中，不足以单独确定新中式。

STYLE-12 个性彩色 / Eclectic、dopamine decor（检索词）
识别：更大胆的配色、图案与家具组合，强调个人偏好。
方法：控制重复色、材质和轮廓，建立视觉联系。
误判：品牌预测中的彩色方向，不等于所有消费者实际选择彩色。

三、色彩知识与搭配建议

1. 色彩字段
记录色相、冷暖倾向、明度、饱和度、覆盖位置、估计面积、表面光泽和光照条件。
品牌色号与屏幕色值分别保存。HEX/RGB是屏幕近似值，不是油漆配方；照片取色受白平衡、曝光和压缩影响。
“暖白”不是一个统一色号，同名商品也可能不同。

2. 六套起始配色（编者建议，不是品牌原样板或流行度排名）
PALETTE-01 暖自然：暖白背景＋浅橡木＋米色石纹＋少量深棕；适合暖极简和自然现代。
PALETTE-02 棕绿层次：奶白＋胡桃木＋低饱和绿＋少量暖金属；适合自然现代和复古取向。
PALETTE-03 沙色海岸：沙白＋浅木＋浅蓝绿＋亚麻；适合现代海岸。
PALETTE-04 深浅对比：浅灰褐＋深木＋灰白石纹＋少量黑；适合Japandi和现代取向。
PALETTE-05 陶土温暖：米白＋陶土色＋自然木色＋柔和织物；适合自然现代和手工感空间。
PALETTE-06 彩色重点：浅中性色＋一处酒红、蓝或绿重点＋重复的小面积同色；适合个性化空间。

3. 搭配判断
先确定大面积背景，再选柜体、地面、台面，最后处理金属和软装。
同是米色，也要比较偏黄、偏红或偏灰的底色。大面积纹理要检查方向与重复频率。
60:30:10可作构图练习，不是强制配色比例；不凭照片伪造精确面积。
在实际空间与日夜光照下比较实体样板；效果图的同色不证明不同品牌实物完全一致。

四、材料、图案和表面触感的分层词典

MATERIAL-01 天然石材 / Natural stone
类别包括大理石、花岗岩、石灰岩、洞石等。天然纹理与批次差异需要看实板。
常见描述：脉纹、颗粒、孔洞、层理。石种、处理方式和使用条件共同决定维护要求。
图片中写“疑似某石种”，采购时核对样板、技术资料和板号。

MATERIAL-02 石纹瓷砖、瓷质大板 / Stone-look porcelain
视觉可模仿天然石材，图案可能重复。纹理图案和真实基材分别记录。
确认：产品分类、规格、厚度、表面、可用版面与边缘加工说明。
“岩板”属于市场常用词，仅凭该词不足以判断精确材料体系。

MATERIAL-03 工程石及其他复合台面 / Engineered surfaces
必须区分树脂复合石、瓷质或烧结类表面、实心面材等具体产品类别。
不得将所有“人造石”“岩板”“石英石”视为同一种材料。澳大利亚供货与加工要求需依据当前法规和产品成分另行核对。

MATERIAL-04 实木 / Solid timber
木种、含水状态、结构、表面处理分别记录。木材色差、拼接与季节性变化需考虑。
不能从木纹照片确认整件家具为实木。

MATERIAL-05 天然木皮 / Timber veneer
薄木层贴在基材上，仍需记录基材、胶合体系与面漆。可通过选皮、排版形成连续或对称纹理。
不能把木皮等同于实木板，也不能把仿木纹印刷面称为天然木皮。

MATERIAL-06 饰面板 / Decorative panels
分别记录刨花板、MDF、胶合板等基材，与三聚氰胺饰面、HPL、木皮、覆膜或漆面等表面体系。
防潮板不等于可长期浸水；饰面耐污不代表切口和接缝同样耐水。

MATERIAL-07 HPL / High-pressure laminate
高压装饰层压板可作为饰面与基材组合；紧凑型层压板是需另行确认的产品类别。
名称中的“防火板”不能单独证明满足指定防火等级；以具体测试与应用条件为准。

MATERIAL-08 皮革与仿皮 / Leather and leather-look surfaces
真皮、PU/PVC仿皮、皮纹压花板和皮纹涂层分别标注。
皮纹可呈细粒、粗粒、十字纹等；视觉图案不能证明动物来源、耐磨或阻燃等级。

MATERIAL-09 织物 / Textiles
常见视觉有亚麻感、平纹、斜纹、粗织、圈圈纱、绒面、人字纹。
成分与织法分开记录。亚麻感不等于100%亚麻；柔软触感不能只凭照片确定。

MATERIAL-10 金属饰面 / Metal finishes
拉丝、抛光、喷砂、粉末涂层、电镀与PVD属于不同处理方式。
不锈钢色不一定是不锈钢，黄铜色不一定是实黄铜。确认基材、表面处理、方向及使用环境。

MATERIAL-11 玻璃 / Glass
透明、磨砂、长虹、夹层、彩色等描述可重叠。长虹是纹理表现，不能据此确认安全玻璃种类。

MATERIAL-12 肌理墙面 / Textured wall finishes
微水泥、灰泥、石灰类涂层、艺术涂料和仿水泥漆不应混为同一系统。
墙面视觉粗糙或无缝，不证明防水、可用于淋浴区或能跨基层裂缝。核对完整基层与涂层体系。

五、纹理及加工词典

TEXTURE-01 石纹 / Stone veining：图案类别；记录直线、云状、网状、颗粒或孔洞感，另记天然/印刷/未知。
TEXTURE-02 木纹 / Wood grain：直纹、山纹、结疤纹等为视觉描述；不单独证明树种。
TEXTURE-03 皮纹 / Leather grain：表面颗粒或压花效果；另记真皮、仿皮或压纹板。
TEXTURE-04 布纹 / Fabric texture：织物组织或仿织物图案；另记真实纤维或印刷压纹。
TEXTURE-05 拉丝 / Brushed finish：方向性细线表面；记录走向和相邻部件方向一致性。
TEXTURE-06 肤感 / Soft-touch：营销和触感描述；确认具体涂层，不自动推导抗指纹或耐刮性能。
TEXTURE-07 同步纹 / Synchronised pore、embossed-in-register：压纹与装饰图案对应，比普通无对应压纹更强调视觉触感一致。见SRC-09。
TEXTURE-08 浮雕压纹 / Embossed texture：形成凹凸表面；确认深浅、耐清洁性与基材。
TEXTURE-09 哑光、超哑、高光 / Matt、super-matt、high gloss：光泽描述；品牌测试条件不同时不可直接比较数值。
TEXTURE-10 仿洞石：孔洞状视觉可以由印刷或涂层模拟；不代表天然孔洞，也不直接证明需要填孔。

PROCESS-01 连纹 / Vein matching
相邻版面尽量形成纹理延续。应记录板号、方向、切割图、接缝和纹理对应位置。
PROCESS-02 对纹 / Bookmatching
利用成对或镜像纹理形成对称关系；不等于所有图案都能从同一块板随意实现。真实产品需核对配套版面。
PROCESS-03 木皮拼纹
记录所用木皮顺序与拼接方式；bookmatch和slip match等方式效果不同。产品照片不证明具体拼法。
PROCESS-04 拉槽 / Grooving、fluting
区分基材开槽、成型板与表面图案。沟槽改变厚度、边缘与清洁方式；深度和间距需节点依据。
PROCESS-05 封边 / Edge banding
记录封边材料、厚度、花色、胶合与切口处理；不能仅凭“无缝封边”断言永久无可见胶线或完全防水。
PROCESS-06 圆弧成型 / Curved fabrication
可能通过弯曲基材、层压、分片拼接、造型基层或专用成型产品实现。照片不能确定内部工艺。
PROCESS-07 表面喷涂、覆膜、贴皮
分别记录工艺，不能以同样外观推定相同耐用性和维修方式。

六、收口及施工节点知识

DETAIL-01 海棠角
类别：阳角处理的中文常用术语，不同材料与地区用法存在差异。
核心：通过倒角、留边或凹缝等截面处理改善阳角外观与尖锐边缘；应以节点剖面确定实际形式。
不能把“海棠角”“45°碰角”“凹槽阳角”列为所有场景下完全相同的同义词。
需记录：材料、板厚、倒角形式、保留边、缝形、填缝或粘接体系、基层与支撑。
检查：边缘是否崩裂、接缝是否一致、是否存在尖锐暴露边、纹理和颜色是否协调。
来源：SRC-01可作中文图示入口，但文件是征求意见稿；不要用它证明现行强制要求。

DETAIL-02 45°碰角 / Mitred corner
两侧边缘以斜切形成转角。是否留边、胶合或留缝由材料与系统决定。
关注：薄边损伤、背面支撑、接缝、搬运与实际产品可加工性。不得统一指定磨成刀口。

DETAIL-03 阳角条 / Tile edge profile
用型材完成暴露边和外角保护；可有方形、圆弧等外露形状。
选择依据包括材料厚度、位置、接缝、型材材质与使用环境。安装遵从所选型号说明。见SRC-10。
阳角条本身不替代完整防水系统。

DETAIL-04 阴影缝 / Shadow gap、reveal
利用凹入缝或型材形成分离感。记录基层、缝形、遮光、固定与清洁方式。
“看起来悬浮”不能证明构件真以悬挑方式承重。

DETAIL-05 不同材料平接
记录双方厚度、标高、边缘保护和变形处理。饰面缝、胶缝与伸缩缝分别识别。
不得默认所有接缝都可用刚性填缝剂封死。

DETAIL-06 压条、嵌条与高低差过渡
用于交接、遮边或高度转换；具体型材应与材料和场景对应。记录外露宽度和实际高差。

DETAIL-07 踢脚线与齐平踢脚
明装、嵌入、凹入等分别记录。齐平方案涉及墙体基层和地面交接，不能事后只靠薄条保证齐平。

DETAIL-08 无踢脚线视觉
记录墙脚保护、地面变形缝及清洁方式；照片中不可见踢脚不等于没有节点处理。

DETAIL-09 隐形门、齐平门
核对门框、铰链、开门方向、饰面厚度、检修和门缝；风格照片不能证明防火或隔声能力。

DETAIL-10 悬浮柜
记录柜体、自重、预期荷载、墙体类型和固定系统。结构承载需要依据，不能凭效果图确定安装方法。

DETAIL-11 圆弧墙、圆弧柜
核对半径、饰面可弯性、基层、边缘和接缝。石材、木皮、层压板、涂层的成型方式不可互换。

DETAIL-12 台面边缘、挡水与水槽交接
区分加厚边、真实板厚、挡水、台下盆、台上盆和其他接合方式。开孔、支撑与胶粘体系应查厂家手册。见SRC-11。

DETAIL-13 格栅、条板
记录实体构造还是纹理图案，条宽、间距、背板与固定均需依据；格栅外观不证明吸声性能。

DETAIL-14 灯槽和灯带
记录灯具、型材、扩散罩、驱动与检修；照片的灯色不等于准确色温，也不证明照度达标。

八、三套关联示例（均为编者构思，非真实已核验工程）

CASE-01 暖自然客厅
风格：暖极简＋自然现代。
配色：暖白墙、浅木柜、米色石纹背景、深棕点缀。
材料层：石纹背景可能为天然石、瓷质大板或其他饰面，未选产品时保持未知。
工艺层：先确定排版与边缘，再选择平接、阴影缝、海棠角或型材方案。
需确认：实体色差、版面重复、基层、支撑、留缝和安装系统。
应采集：全景、石纹近景、转角实景、剖面图、施工过程。

CASE-02 胡桃木与绿色厨房
风格：自然现代＋中世纪现代取向。
配色：低饱和绿门板、胡桃木视觉柜体、浅色台面、少量金属。
材料层：胡桃木视觉可能来自木皮或印刷饰面；绿色门板可能是漆面、覆膜或其他板材体系。
工艺层：封边、门缝、纹理方向、台面开孔与水槽交接。
需确认：产品成分、当地供货条件、清洁、热源距离和厂家加工手册。

CASE-03 浅石纹浴室
风格：暖现代。
配色：暖灰白石纹、浅木视觉柜、少量深色或金属配件。
工艺层：砖排版、阴阳角、墙地交接、壁龛边缘与排水。
需确认：湿区适用、防水体系、地面防滑、坡度与固定。好看的阳角不能替代湿区系统设计。

十、AI答复模板及示范

图片分析答复顺序：
1. 整体风格判断与依据。
2. 主色、辅色、点缀色和光泽。
3. 各对象的可见纹理，以及可能的基材或饰面候选。
4. 可见加工和收口形式。
5. 实现同类效果的材料组合与替代选项。
6. 需要确认的产品、尺寸和节点。
7. 来源与判断限度。

示范问：这张米色石纹墙是真洞石吗？
答：能观察到洞石感纹理；仅凭照片不能确认天然洞石。候选包括天然洞石、仿洞石瓷质板和其他仿石饰面。需要产品型号、侧面与背面照片或实体样板进一步确认。

示范问：海棠角就是45°碰角吗？
答：一些做法有关联，但不能一概等同。海棠角在不同材料和地区有不同截面形式，应看是否留边、留槽、留缝及实际节点图，再确定做法。

示范问：皮纹柜门就是包真皮吗？
答：皮纹描述外观或压纹，可能来自真皮、仿皮、覆膜或饰面板。需要确认基材与表面体系，不能从皮纹名称直接推出真皮。

示范问：给我一个目前流行的自然暖色客厅组合。
答：可参考暖白背景、浅木、米色石纹和少量深棕的组合；这是搭配建议。澳大利亚HIA 2026/27文章提供自然材料和触感方面的趋势依据，但不证明这套组合是销售第一。见SRC-02。

示范问：可以按图直接施工吗？
答：先把图片转成材料表和节点需求，再由产品资料和施工图确认尺寸、基层、安装及使用条件。照片可指导效果，不能提供全部隐藏构造。

十二、后续图文补充方式

这版先建立术语、判断规则和来源关系。给AI识图时，将实际图片或包含图片的PDF与本文件一起提供。

先选择一个具体工艺，例如海棠角，完整标注一种材料的一组图片，再扩展到其他材料，避免名称相同却截面不同。
有授权的自有照片优先；开放资产保留来源和许可；厂商或设计师作品按具体使用条款处理。
每次更新新增版本、日期和资料清单。未知值保持未知，核验后再补，不能用推测覆盖原始记录。
